# DC MOTRIX

Sitio web del taller automotriz DC MOTRIX.

La publicación se realiza mediante GitHub Actions y GitHub Pages. El flujo de publicación extrae el prototipo incluido en el repositorio y lo despliega como sitio web estático.

Nota: el panel de administración y los formularios del prototipo son demostrativos; todavía no cuentan con backend, base de datos ni autenticación real.
